# Survival Cashflow

**[👉 アプリを実際に使ってみる（Live Demo）](https://survival-cashflow.vercel.app/)**


シンプルかつサバイバルな資金繰り管理アプリです。
日々の残高推移を可視化し、資金ショートを防ぐための直感的なインターフェースを提供します。

Features (特徴)
収入・支出の予定を入力し、日々の残高推移を自動計算

資金がマイナスになる日をアラート表示

JSON形式でのデータのエクスポート/インポートによるバックアップ

⚠️ Important Note (注意事項)
本アプリのデータは、お使いのブラウザのローカルストレージにのみ保存されます。
サーバー等には送信されませんが、ブラウザのキャッシュや閲覧履歴をクリアするとデータがすべて消失します。 定期的にエクスポート機能でバックアップを取ることをお勧めします。

All data is stored locally in your browser. Clearing your browser cache or history will delete all your data. Please use the export feature regularly to back up your data.
